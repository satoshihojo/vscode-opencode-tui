# Contributing

Issues and pull requests are welcome.

## Before Opening a PR

- Run `npm run verify` on Linux.
- On macOS or Windows, run `npm run check-types`, `npm test`, and `npm run package`.
- Keep changes focused and include tests when behavior changes.
